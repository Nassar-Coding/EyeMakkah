# EyeMakkah — نشر على Vercel (سحب وإفلات)

نموذج تفاعلي جاهز للنشر. لا يحتاج بناءً ولا تثبيت حزم.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | صفحة التطبيق |
| `app.js` | التطبيق كاملاً (مبني مسبقًا) |
| `vercel.json` | إعدادات الاستضافة ورؤوس الحماية |
| `robots.txt` | يمنع الفهرسة |
| `PHOTO_SOURCES.md` | مصادر الصور وشروط الاستبدال قبل الإطلاق |

## النشر

1. افتح **vercel.com/new**
2. اسحب مجلد `dist` بالكامل إلى الصفحة
3. **Framework Preset**: اختر **Other**
4. اترك **Build Command** و **Output Directory** فارغَين
5. اضغط **Deploy**

يفتح التطبيق على العربية مباشرة. المقاس المستهدف للعرض: شاشة ٣٩٠ × ٨٤٤ داخل إطار ٤١٢.

## ملاحظة مهمة

هذا نموذج منتج. القيم التشغيلية والعروض والمساهمات والمشاركين توضيحية،
ولا تمثل معلومات حيّة. الصور التعبيرية مرسومة داخل التطبيق ويجب استبدالها
بصور مرخّصة على CDN خاص بكم قبل أي إطلاق عام.
