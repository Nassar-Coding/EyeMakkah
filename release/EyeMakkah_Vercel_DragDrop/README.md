# EyeMakkah — نشر على Vercel (سحب وإفلات)

نموذج تفاعلي جاهز للنشر. لا يحتاج بناءً ولا تثبيت حزم.

يبدأ التطبيق من شاشة الغلاف، ثم اختيار اللغة (العربية / English)، ثم يدخل مباشرة إلى
التطبيق. الصور الفوتوغرافية الحقيقية (٤٤ صورة) مضمّنة داخل `app.js`، فلا يعتمد النموذج
على أي مستضيف صور خارجي.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | صفحة التطبيق |
| `app.js` | التطبيق كاملاً (مبني مسبقًا، والصور مضمّنة فيه) |
| `vercel.json` | إعدادات الاستضافة ورؤوس الحماية. يُعاد التحقق من `app.js` مع كل نشر، فيرى الزوار السابقون النسخة الجديدة فورًا |
| `robots.txt` | يمنع الفهرسة |
| `manifest.json` | وصف الحزمة: المحتوى والوسائط والتحقق |
| `PHOTO_SOURCES.md` | مصدر كل صورة، ودرجتها (صورة المكان نفسه / سياقية من مكة / عامة)، وما بقي عامًا ولماذا |
| `BUILD_INFO.txt` | تاريخ البناء وحجم الحزمة |

## النشر

1. افتح **vercel.com/new**.
2. اسحب هذا المجلد بالكامل إلى الصفحة.
3. في **Framework Preset** اختر **Other**.
4. اترك **Build Command** و **Output Directory** فارغَين.
5. اضغط **Deploy**.

على الجوال يملأ التطبيق الشاشة. على الشاشات الواسعة يظهر داخل إطار جوال بعرض ٣٩٠.

## ملاحظة مهمة

هذا نموذج منتج، وقيمه التشغيلية وعروضه ومساهماته وأعداد مشاركيه توضيحية لا تمثل معلومات حيّة.

جميع صوره فوتوغرافية، وتحت كل صورة في صفحة القرار ما يبيّن درجتها:
- صورة المكان نفسه
- أو صورة سياقية من مكة
- أو صورة عامة

راجع `PHOTO_SOURCES.md`، وأكّد حقوق كل صورة قبل أي إطلاق عام.
