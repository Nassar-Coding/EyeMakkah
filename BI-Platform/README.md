# EyeMakkah Business Intelligence — Interactive Mockup

نموذج تفاعلي مستقل لمنصة **ذكاء الأعمال لـ EyeMakkah**. الواجهة عربية وRTL، والبيانات المعروضة اصطناعية/توضيحية لأغراض تصميم وتجربة المنتج فقط.

## التشغيل محليًا

```bash
python -m venv .venv
source .venv/bin/activate   # macOS / Linux
# .venv\Scripts\activate    # Windows
pip install -r requirements.txt
streamlit run app.py
```

ثم افتح الرابط الذي يظهر في الطرفية، وعادةً يكون:

```text
http://localhost:8501
```

## ما يتضمنه النموذج

- لوحة المعلومات التنفيذية
- تحليل الطلب وسلوك البحث
- تحليل المناطق
- الأنشطة والتجارب مع فصل دلالات Save / Plan / Join / Action / Complete
- المجتمعات والاهتمامات
- الحملات والعروض
- الفرص والفجوات كدعم قرار
- مركز تقارير مع تصدير CSV
- فلاتر عامة للفترة والمنطقة والقطاع ونوع الجمهور
- بيانات اصطناعية ثابتة seed لضمان ثبات العرض بين مرات التشغيل

## ملاحظات

- لا توجد قاعدة بيانات أو API أو مصادقة حقيقية.
- لا يتم عرض أي معلومات شخصية أو هوية مستخدم.
- لا تمثل الأرقام بيانات تشغيلية حية لـ EyeMakkah أو مكة.
